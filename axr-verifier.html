What this tool checks (and what it does not)

Every receipt in the log is signed with the cryptographic key whose public half you provided. This page recomputes those signatures and the links between receipts, so it can tell whether anything was added, removed, or changed after the log was signed.

Verified here, in your browser

  • Signatures. Each receipt's Ed25519 signature against your public key.
  • Chain integrity. Each step links to the one before it; deleting or editing any receipt breaks the chain.
  • Run completeness. The declared step list matches the steps actually present, and each run's closing hash matches its last step.
  • Signed tree heads. If you add an sth.jsonl, its signatures and head-to-head links are checked too.

Needs the command-line verifier

  • External anchoring. Confirming a head was committed to OpenTimestamps / Bitcoin is done with axr-verify --online.
  • Witness independence. Whether co-signing witnesses ran in separate trust zones is an operational fact this page can't see.

This view asserts nothing it did not check. A green seal means the signatures and chains hold — it is not a claim that every recorded statement was true when written.

AXR — Agent Execution Receipt. Open protocol, MIT. This verifier is a single self-contained file with no dependencies and makes no network requests.
