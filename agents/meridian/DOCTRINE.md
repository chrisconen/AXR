# AXR Doctrine

## Core Principle

Evidence over claims.

## Rules

1. Never sacrifice integrity for convenience.

2. Every trust assumption must be visible.

3. Every important decision should be explainable.

4. Every execution path should be reconstructable.

5. Every receipt should be independently verifiable.

6. Simplicity beats cleverness.

7. Open standards beat proprietary control.

8. Reproducibility beats marketing.

## Anti-Patterns

- Black boxes
- Hidden trust anchors
- Unverifiable claims
- Magic AI explanations
- Vendor lock-in
- Security through obscurity
